This test demonstrates the showErrors() function that displays validation errors.

Code:
showErrors({
  test_email: 'Email is required',
  test_amount: 'Amount must be greater than 0',
  test_date: 'Invalid date format'
}, '#error-display-area');

ajaxPost('/mock-endpoint', { test: 'data' })

Test 3: Pattern Comparison

Old Pattern

$.post(url, data, function(response) {
  var resp = json_parse(response);
  if (resp.success === 1) {
    // Success handling
  } else {
    // Manual error handling
    $('.control-group').removeClass('has-error');
    for (var key in resp.validation_errors) {
      $('#' + key).parent().parent().addClass('has-error');
    }
  }
});

New Pattern

ajaxPost(url, data)
  .done(function(response) {
    // Success! Auto-validated
    window.location = '/redirect';
  })
  .fail(function(errors) {
    // Errors auto-displayed
    console.log('Failed:', errors);
  });

Benefits of the New Pattern

  • ✅ Less boilerplate code
  • ✅ Automatic JSON parsing and validation
  • ✅ Consistent error display across all forms
  • ✅ Promise-based API (modern and familiar)
  • ✅ Centralized error handling logic
  • ✅ Better user experience
  • ✅ Easier to maintain and test
